Updating

New versions of these plugins add features and fix problems. They do not arrive by themselves unless you switch that on. Pick one of the two ways below.

  • Why not automatic
  • A. Turn on auto-update
  • B. Update now
  • Several accounts
  • Your version

Why mods do not update by themselves

Claude Code keeps each plugin's files on your computer. It updates them for you only when the marketplace they came from has auto-update turned on. That is on by default for Anthropic's official marketplaces, and off by default for every other marketplace, including this one. So until you switch it on, you stay on the version you installed.

A. Turn on auto-update (do it once)

This follows Claude Code's own documentation (Keep plugins updated).

  1. In a Claude Code chat (desktop app or terminal), type /plugin.
  2. Go to the Marketplaces tab.
  3. Select horef-claude-plugins to open its menu.
  4. Turn auto-update on.

From then on, after a session starts, Claude Code refreshes the marketplace and updates the plugins you installed from it. When it does, you may see Plugin updated: <name> · Run /reload-plugins to apply. Type /reload-plugins in that chat. If you do not, the new version loads the next time you start Claude Code.

The same documentation says the exact timing, the plugins auto-update skips, and the environment variables that turn it off are on its "When auto-update runs" page.

B. Update now

Use this when you want the new version at once, or when you prefer not to use auto-update. Pick the way that suits you.

B1. Ask Claude to do it (works in the desktop app too)

Paste this into a chat, changing the plugin name if it is not model-router:

Please update my model-router plugin: run `claude plugin marketplace update horef-claude-plugins` and then `claude plugin update model-router@horef-claude-plugins`, tell me what version I have now, and remind me to type /reload-plugins in my open chats.

When a mod finds a newer version it shows an Update notice. The Update button puts exactly this request in your chat box, and you press Enter. Both mods also have a command that checks now and prints the installed and latest versions: /router update and /status-line update.

The mods look for a new version on GitHub at most once a day, quietly; if it fails (offline, a blocked network) you see nothing. To stop it: in model-router, Settings → Diagnostics → Check for updates; in the status line, /status-line update-check off; for every mod at once, set the environment variable CLAUDE_PLUGINS_NO_UPDATE_CHECK=1.

B2. In the plugin panel

  1. Type /plugin.
  2. To update one plugin: open the Installed tab, open the plugin, and choose Update now.
  3. To update everything you installed from this marketplace: open the Marketplaces tab, select horef-claude-plugins, and choose Update marketplace. It refreshes the listing, updates your installed plugins from it, and says if it left any for you to update yourself.

B3. In a terminal

claude plugin marketplace update horef-claude-plugins
claude plugin update model-router@horef-claude-plugins
claude plugin update session-status-line@horef-claude-plugins

The first line refreshes the list of what is available. It does not change your installed plugins by itself; the claude plugin update lines do. There is no single command that updates every plugin, so repeat the last line for each plugin you use (for example herdr-delegate@horef-claude-plugins).

Then: load it

New chats pick up the new version by themselves. In a chat that is already open, type /reload-plugins.

If you use several Claude accounts

Each account has its own folder (CLAUDE_CONFIG_DIR, default ~/.claude) and keeps its own plugins, so each account updates on its own. Do option A or B once in a chat of each account. In a terminal, point the command at the account's folder:

CLAUDE_CONFIG_DIR=~/.claude-uni claude plugin update model-router@horef-claude-plugins

Auto-update, the Update notice and the version check also work per account, so each account notices on its own.

Which version do I have?

In a terminal, run:

claude plugin list

It prints each plugin with its Version, Scope and Status. You can also type /plugin and open the Installed tab. To see what changed, read the plugin's CHANGELOG.md on GitHub, for example model-router's.
