Claude plugins, explained

This is Sergiy Horef's marketplace of plugins for Claude Code: two mods that add a panel or a status line to your chat, and a set of skills that teach Claude how to do specific jobs. This site shows you how to start with each, step by step.

The two mods

A mod changes what Claude Code itself shows you. Both are optional, and both work without any extra setup.

model-router

Plans multi-step work, runs each step on the cheapest Claude model that does it well, and shows what it cost and saved. Your main chat's model never changes.

Start with model-router

session-status-line

A compact line above your prompt: model, how full the context is, your 5-hour and weekly limits, cost, and more. Optionally keeps a waiting chat's cache alive.

Start with the status line

The skills

Skills need no setup beyond installing them. Claude picks one up when your request matches it, or you can ask for it by name.

  • strange-loopMakes skills and tools improve themselves from use, with evidence-gated reviews.
  • project-foundationsSets up, upgrades or audits a repo so agents and humans can maintain it (AGENTS.md, status, decisions, doc checks).
  • scientific-figuresDraws figures for notes, papers and slides: circuits, anatomy, plots, phase portraits, 3D surfaces.
  • gui-designDesigns panels, settings pages, viewers and dashboards at the right density, and checks them with screenshots.
  • research-writingTurns results, logs and figures into a coherent write-up or paper draft in LaTeX.
  • literature-researchSearches several sources, records every finding with its quote, and checks claims against the sources.
  • research-assistantTakes a research question through literature, hypotheses, analyses and write-up, stopping for you at three gates.
  • local-run-queueRuns many local jobs in parallel inside a memory budget.
  • model-routingThe model-router approach as a plain skill, for agents without the mod (GitHub Copilot, Kiro, Codex, Cursor, claude.ai).
  • herdr-delegateHands self-contained steps to helpers on your other subscriptions. Used by model-router's helpers.
  • course-lecture-notesTurns a lecture into teaching notes (written for one person's setup: DEVONthink, Anki).
  • paper-premarkPre-reads and marks up a scientific paper in DEVONthink (written for one person's setup).

Install anything in 3 steps

  1. Open Claude Code. In the desktop app, use the Code tab. In a terminal, type claude. Click in the chat box.
  2. Type the install command, with the plugin's name. For example, for model-router: 
    /plugin install model-router --marketplace Horef/claude-plugins
    The first time, Claude Code shows the marketplace it found and asks you to confirm adding it. Then it shows the plugin's details and asks where to install it. Install for you (user scope) is the usual choice.
  3. Load it. New chats load it by themselves. In a chat that is already open, type /reload-plugins.

Prefer a shell? claude plugin install model-router --marketplace Horef/claude-plugins does the same without opening a chat. Plugin names are the ones in the lists above.

Updating

Plugins from this marketplace do not update by themselves unless you switch that on: Claude Code only auto-updates official marketplaces by default. You can switch auto-update on once, or update on request whenever you like. How to update, step by step.

Source and issues: github.com/Horef/claude-plugins. The mods use Claude Code's mod (function-hooks) interface, which is in early access and may change, so they need a recent Claude Code.
