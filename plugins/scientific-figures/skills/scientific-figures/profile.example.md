# scientific-figures profile (example)

Copy to `~/.config/scientific-figures/profile.md` and edit. The skill reads it at setup (section 0, step 3); each line overrides the default in SKILL.md. It holds one person's choices, so it stays outside every repository. In a chat app without file access, put the same lines in your standing instructions.

- audience: students learning alone from study notes   # or: researchers in <field>; a general audience
- targets: devonthink-markdown, latex-paper             # devonthink-markdown | markdown | latex-paper | slides | png
- flashcards: yes (Anki) - every figure is also described in prose in the note
- neurons: simple schematic glyphs; real-looking only on request
- house style: default                                   # or name the deviations, e.g. "font: Arial"
- notes: anything else agents should always do with your figures
