# Morphology library

Real neuron reconstructions for figures. Credit the source in every caption; for publication prefer the NeuroMorpho.Org (CC BY) version of a cell and cite the original paper.

- **L23_pyramidal.swc** - Blue Brain Project NMC portal (Markram et al. 2015), rat somatosensory cortex; via OpenSourceBrain/BlueBrainProjectShowcase. Licence: check NMC portal terms (CC BY-NC-SA). (original file `dend-C170897A-P3_axon-C260897C-P4_-_Clone_4.asc`)
- **L23_pyramidal_b.swc** - Markram lab, NeuroMorpho.Org standardised (CNG) version; via LFPy examples. NeuroMorpho data: cite NeuroMorpho.Org + original paper. (original file `C010398B-P2.CNG.swc`)
- **L5_thick_tufted.swc** - Blue Brain Project, rat L5 TTPC C060114A7 (Hay et al. 2011 model); via BluePyOpt examples. Licence CC BY-NC-SA 4.0. (original file `C060114A7.asc`)
- **L4_spiny_stellate.swc** - Blue Brain Project NMC portal, L4 spiny stellate (NeuroML export); via OpenSourceBrain. Axon replaced by a stub in the model. (original file `cADpyr230_L4_SS_1afeb14f17_0_0.cell.nml`)
- **L4_martinotti.swc** - Blue Brain Project NMC portal, L4 Martinotti cell (NeuroML export); via OpenSourceBrain. Axon replaced by a stub. (original file `bAC217_L4_MC_5fa0a62bd0_0_0.cell.nml`)
- **L23_large_basket.swc** - Blue Brain Project NMC portal, L2/3 large basket cell; via OpenSourceBrain. (original file `C050398B-I4_-_Scale_x1.000_y1.050_z1.000.asc`)
- **L23_nest_basket.swc** - Blue Brain Project NMC portal, L2/3 nest basket cell; via OpenSourceBrain. (original file `C300898C-I3_-_Scale_x1.000_y0.950_z1.000_-_Clone_20.asc`)
- **L1_HAC.swc** - Blue Brain Project NMC portal, L1 horizontal axon cell; via OpenSourceBrain. (original file `sm081119a6.asc`)
- **L6_tufted_pyramidal.swc** - Blue Brain Project NMC portal, L6 tufted pyramidal (NeuroML export); via OpenSourceBrain. Axon replaced by a stub. (original file `cADpyr231_L6_TPC_L4_117b9dfb71_0_0.cell.nml`)
- **thalamocortical.swc** - Blue Brain Project thalamus (Iavarone et al. 2019), rat VPM thalamocortical cell; via BluePyOpt examples. Licence CC BY-NC-SA 4.0. (original file `jy160728_A_idA.asc`)
- **purkinje.swc** - Cerebellar Purkinje cell (NeuroML, OpenSourceBrain/PurkinjeCell, from NEURON ModelView export). (original file `purk2.cell.nml`)
