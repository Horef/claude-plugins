# gui-design profile (example)

Copy to `~/.config/gui-design/profile.md` and edit. The skill reads it at setup (section 0); each line overrides the default in SKILL.md. It holds one person's choices, so it stays outside every repository. In a chat app without file access, put the same lines in your standing instructions.

- audience: me alone                       # or: my team; students; strangers who install the tool
- surfaces: browser, desktop app, terminal # where the GUI runs; each has limits (references/surfaces.md)
- density: balanced                        # minimal | balanced | explained
- explain: one line where not obvious, more one click away   # or: always inline; docs only
- liked: apps or pages whose look you want, and what you like about them
- disliked: what makes a GUI unusable for you
- themes: light and dark
- notes: anything else agents should always do with your GUIs
