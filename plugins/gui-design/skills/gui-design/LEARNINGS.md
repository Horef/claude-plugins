## Resolved
- O14 2026-11-04 [win] 8 Rework: the Replay page improved in five small rounds of owner feedback (fill the window; one Make button; inhibition shown; colours and zoom; full descriptions), each one commit with lint and shots. Three of the later rounds are what a 'what will the next experiment need?' pass in section 1 would have caught up front. (claude-code, simple_complex_v1) → 0.4.0
- O13 2026-11-04 [missing] 3 Pattern: a dense spatial canvas (a 3D neuron with ~2000 contacts) shipped with rotate but no zoom; the owner had to ask. Rule wanted: a canvas whose marks can be denser than about 1 per 5 px gets zoom about the pointer (wheel/pinch), pan (shift- or middle-drag), double-click reset and +/- buttons, marks scaled ~sqrt(zoom), off-panel labels hidden; compared panes share the view. (claude-code, simple_complex_v1) → 0.4.0
- O12 2026-11-04 [missing] 4 Visual calm: overlay classes on a drawing (PV teal, SST indigo triangles on blue/cyan Vm-coloured dendrites) were chosen apart by hue only; on the real drawing both read as the branch blue. Rule wanted: choose overlay colours against the base layer's own palette (a warm pair against cool branches) and separate them in lightness, so they read apart as 2-px dots; check in a shot at the real density (1900 contacts). (claude-code, simple_complex_v1) → 0.4.0
- O11 2026-11-04 [missing] 1 Before building: the Trial picker and its label were written for the stimulus fields of the experiments of the day (grating, bar); when runs with PV/SST inhibition arrived, what made two replays different (a model setting of the condition, not a trial field) was invisible, and the label was truncated. The owner asked that planning each screen include the future: which things will vary later (new parameters, tests, properties), and render them generically. Fix that worked: derive descriptions from the data (every stimulus field named from key + unit suffix, varying fields bold; a condition = every config value that differs across its siblings, nothing named in advance) and show the full text wrapping under the picker, keeping the picker label short. Rule wanted in section 1: ask 'what will vary next?' and prefer data-driven labels and diffs over hand-listed fields. (claude-code, simple_complex_v1) → 0.4.0
- O10 2026-11-03 [missing] 2 layer rule: an empty state had two competing Make buttons (primary in the slot without progress, secondary in an expander with the job panel) plus a Display popover with nothing to display. Rule wanted: one action per outcome, its progress/error shown next to the button that started it; controls for a view only render when the view does. (claude-code, simple_complex_v1) → 0.4.0
- O9 2026-11-03 [missing] 6 Surfaces: embedded viewers were built as fixed-height iframes with scrolling=True and a square main canvas (height = width), giving a double scroll and traces below the fold on wide screens. Missing rule: a sovereign viewer embedded in a page fills its frame (100vh flex layout, no inner scroll), splits height between views with a splitter, and in Streamlit >= 1.52 uses st.iframe(height='content') with the page sizing itself to window.parent.innerHeight; resizing frameElement from inside does NOT work (Streamlit's wrapper keeps the old height and overlaps the next element). Also: shot.py --full grows the viewport, so window-fitted content grows with it. (claude-code, simple_complex_v1) → 0.4.0
