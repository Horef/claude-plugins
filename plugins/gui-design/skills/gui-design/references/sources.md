# Sources

The references paraphrase these works; no text is reproduced beyond short phrases. Short names as cited in the reference files.

| Short name | Work | Used for |
|---|---|---|
| RUI | Adam Wathan, Steve Schoger, *Refactoring UI* (2018, rev. 2023) | hierarchy, spacing and type scales, fewer borders, colour, actions |
| DI | Jenifer Tidwell, Charlie Brewer, Aynne Valencia, *Designing Interfaces*, 3rd ed. (O'Reilly, 2020) | named layout, disclosure, list, form and data patterns |
| About Face | Alan Cooper, Robert Reimann, David Cronin, Christopher Noessel, *About Face: The Essentials of Interaction Design*, 4th ed. (Wiley, 2014) | posture, perpetual intermediates, defaults and memory, settings, excise, dialogs and notices |
| Few | Stephen Few, *Information Dashboard Design* (O'Reilly, 2006) | at-a-glance screens, the common dashboard mistakes, alerts and colour |
| Strategic Writing | Torrey Podmajersky, *Strategic Writing for UX* (O'Reilly, 2019) | labels, buttons, help text, errors, empty states, lengths |
| NN/g | Jakob Nielsen, "Progressive Disclosure" (nngroup.com); Page Laubheimer, "8 Design Guidelines for Complex Applications" (nngroup.com) | layers, staged vs progressive disclosure, complex tools |
| Pajamas | GitLab Pajamas Design System, "Progressive disclosure" (design.gitlab.com/patterns/progressive-disclosure) | levels, handles, truncation |
| Distill | Fred Hohman, Matthew Conlen, Jeffrey Heer, Duen Horng Chau, "Communicating with Interactive Articles", *Distill* (2020) | interactive explainers |
| Victor | Bret Victor, "Explorable Explanations" (2011) and "Magic Ink" (2006), worrydream.com | reactive documents, show the data, tight feedback, context instead of questions |
| CLIG | Aanand Prasad et al., *Command Line Interface Guidelines* (clig.dev) | terminal output, brevity, status, colour |

The scale values in `visual-hierarchy.md` are adapted: the text export lost RUI's figures, so they were rebuilt from its stated rule (neighbouring steps at least ~25% apart). Numbers marked "working default" are this skill's choices, not a source's.

Not yet distilled but worth adding when a GUI needs them: Few's later chapters on sample dashboards; DI chapters on navigation and mobile; Tufte *The Visual Display of Quantitative Information*; Johnson *Designing with the Mind in Mind*; Munzner *Visualization Analysis & Design*.
