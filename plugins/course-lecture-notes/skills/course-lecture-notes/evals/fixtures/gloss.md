### 1.1 A key equation with a one-line gloss

In a linear rate unit, the rate follows the input with a gain.

$$r = g I$$

*($r$: rate in Hz; $g$: gain in Hz/nA; $I$: input in nA.)*

Doubling the input doubles the rate.

> **From class.** A student asked whether $g$ can be negative; no, it is a gain.

---

### 1.2 A derivation chain ends in a gloss

Each step follows from the last.

$$\dot x = -x + \lambda x$$

Collecting terms:

$$\dot x = -(1 - \lambda)x$$

*($x$: mode amplitude; $\lambda$: eigenvalue.)*
