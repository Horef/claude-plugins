# Learnings: herdr-delegate

Observations from use, written by the agents that used this skill; the strange-loop skill turns them into changes.
One line each: `- O<n> <date> [<kind>] <section>: <what happened, what would have helped> (<harness>, <context>)`.
Kinds: failure, friction, misled, missing, workaround, win, wish. ` ×N` = seen N times; ` → <version>` = resolved there.

## Open

A worktree-setup checklist in the skill would help. (claude-code, simple_complex_v1)

(claude-code, simple_complex_v1)
- O10 2026-11-06 [friction] Step 4 / helpers.py prompt: Copilot's 'Allow path access' dialog (reading a brief file outside the cwd) blocked the helper, hc wait reported status blocked, but 'helpers.py prompt' printed 'no prompt'; the detector should match that dialog too, and briefs in a scratchpad outside --cwd will always trigger it (put briefs inside the cwd or inline) (claude-code, genome reflection 2026-11-06)
- O12 2026-11-07 [friction] Brief: a Kiro helper testing a config CLI ran it against the real ~/.config because an exported XDG_CONFIG_HOME did not persist between its shell calls; it reported it honestly and could not delete the files (Kiro blocked rm). - O13 2026-11-07 [win] Steps 2-7: a kiro-standard helper briefed through a file inside --cwd updated a 26-row evidence ledger from 15 PDFs, asked one convention question instead of guessing (wanted to drop citation brackets to pass a check; answered no), and its quotes re-checked at 0.97-1.00. (claude-code, simple_complex_v1)
- O14 2026-11-07 [friction] Step 5 Judge: an agy helper (--mode auto) on a 19-row quote-check brief raised about 10 permission prompts (every shell command, each read outside the workspace, its own /tmp cleanup); option 2 (always allow) only covers the exact command prefix, so each new LIT=... script asked again. A brief note to put all quote checks in one script file, or agy's non-workspace 'always allow' up front, would cut the round trips. (claude-code, simple_complex_v1)
- O15 2026-11-08 [friction] kiro-light template runs kiro-cli --effort low, yet the Kiro screen showed 'claude-haiku-5.5 · thinking · medium' (2026-11-08 one-prompt run): the --effort flag may not reach Haiku, or the status line shows a default (claude-code, usage line check)
- O16 2026-11-08 [friction] Step 4 Copilot prompts: helpers.py prompt <name> exited non-zero while Copilot showed an 'Allow path access' dialog (shell path outside the session's allowed paths: the project's conda python); the lead's 8-minute wait loop missed it and the helper sat blocked ~6 min. Would help: prompt detection that also matches Copilot's 'Allow path access' / 'Do you want to allow this?' box. (simple_complex_v1)
- O17 2026-11-08 [friction] Kiro sandbox: a Kiro helper's git push/pull over HTTPS was blocked by Kiro's own policy ('publishes commits to a shared branch'), so the lead had to push. Also an agy judge script that reads only the first line of a multi-line 'python3 -c' prompt cannot see what it approves. Would help: say in the skill that Kiro helpers cannot push (lead pushes), and a helpers.py prompt mode that prints the full command for agy. (simple_complex_v1)
