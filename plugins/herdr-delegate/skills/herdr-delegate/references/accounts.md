# Other Claude accounts

Read when: the person has more than one Claude Code account (`CLAUDE_CONFIG_DIR`), an account is missing or wrongly listed in `pick`/`status`, or you add, remove or exclude an account. Moved from SKILL.md "Helpers" (restructure R4, 2026-11-15).

If you run Claude Code under several accounts (each with its own `CLAUDE_CONFIG_DIR`, e.g. a work or university plan beside a personal one), the others are **found by themselves**: no setup. On a machine with a single account there are none. With two or more, every account appears as a provider `claude<label>` (e.g. `claudeuni` for `~/.claude-uni`, `claudemain` for `~/.claude`) marked `"auto": true` in `helpers.py config`, with the Haiku / Sonnet / Opus tiers (see `providers.md`). Candidates come from (a) the readings files `$XDG_CONFIG_HOME/claude-accounts/<key>.json` (their `config_dir` and `label`; the dir must still exist), (b) the session's own config dir, and (c) `~/.claude` and any `~/.claude-*` / `~/.claude_*` in the home folder that holds a `.claude.json`, `.credentials.json`, `settings.json` or `projects/` entry (an empty or unrelated dir is ignored). `pick`, `status`, `config` and `render` write their templates, only while the `claude` CLI is on PATH. The account whose config dir is the current session's own is skipped by `pick` and `status` ("this account"), so one shared config serves every account.

`helpers.py account list` shows each account (`(auto)` for the found ones), its quota reading and which one is this session's. `account add <name> <config_dir> [--label L]` is for what discovery cannot know: it configures that dir by hand (`<name>` lowercase letters and digits), and replaces the auto entry of the same dir, so a label or name of your own sticks. `account rm <name>` removes either kind; an auto one is recorded in `excluded_accounts` in your override (by key) so it is not found again, and `account add` of that dir brings it back. Quota comes from the readings file that session-status-line writes in each account's sessions (the key is `default` for `~/.claude`, else the first 8 hex of the sha256 of the dir as written): `pick` treats the account as out when 5h is at 95% or more, or 7d at 98% or more, until that window resets (no reading: usable).
