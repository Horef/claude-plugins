# Panel UI

## 1. Layout
Panels are one column, 320-480 px wide, with 8 px spacing.

## 2. Text
- Text is at least 12 px (owner preference: the owner reads panels on a laptop at arm's length).
- Badges use compact 11 px text so they fit in table rows. (added in this pass, for O5)

## Learning loop

Record lessons with the strange-loop note command (strange-loop section 2).
