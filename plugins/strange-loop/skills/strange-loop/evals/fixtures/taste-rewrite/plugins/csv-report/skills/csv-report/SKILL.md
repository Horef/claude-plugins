# CSV report

It is important to always remember that a good report is a report that the reader can actually read, and so it is
very important that the report is short, and also that it is clear, and also that it does not contain everything.

## Steps
1. Run `python3 scripts/report.py --file data.csv` to get the column summary.
2. Pick the three columns the person cares about most; ask if unsure.
3. Write the summary: one sentence per column, then one sentence on what to do next.
